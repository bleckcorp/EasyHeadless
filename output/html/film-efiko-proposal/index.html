01 / Project OverviewFilm Efiko

Project Overview

Project direction

Film Efiko requires a new editorial website that presents its stories with a clear hierarchy, strong imagery and a consistent magazine-style reading experience.

The website will use The Nation's editorial structure as a reference for proportions, typography hierarchy, image ratios, spacing and homepage rhythm while applying Film Efiko's own identity and content requirements.

Technical direction

The public website will be custom-built with Next.js and deployed on Vercel. Film Efiko's present WordPress installation will remain the publishing end.

Gadar's EasyHeadless publishing solution will connect WordPress to the Next.js frontend. EasyHeadless is the Gadar blogging and headless publishing solution used for this project.

Design direction

AreaApproach
StructureThe Nation's editorial hierarchy, image proportions, spacing and homepage rhythm will guide the layout.
BrandingFilm Efiko's logo and brand assets will replace all reference branding.
ColourWhite will be the main background and reading surface, black will be used for text, orange will replace the reference pink or red accent, and blue will be used as a secondary accent.
Content controlWordPress will control articles, images, categories, authors, issues and selected homepage positions.
Design controlFonts, colours, spacing, image ratios, card styles, grids and responsive layouts will remain fixed in code.

05 / Audience FunctionalityFilm Efiko

Email Access, Newsletter and Donations

Email-gated articles

This is an email access gate, not a paid paywall. When publishing an article, the editor can choose whether it is public or email-gated.

1The visitor sees the headline, image and opening portion.
2The visitor enters an email address.
3A short verification code is sent to the email address.
4The visitor enters the code and the full article becomes available.
5Access is remembered on that browser for an agreed period.

WordPress email list

Email addresses submitted through the article access gate will be stored in a dedicated area in WordPress. Authorised Film Efiko users will be able to view and retrieve the list for approved editorial or audience-management purposes.

Newsletter consent will remain separate. Verifying an email address to read an article will not automatically subscribe the reader to marketing messages.

Newsletter integration

The Next.js frontend can be connected to the newsletter platform selected by Film Efiko. The subscription form, confirmation messaging and destination list will be configured for that provider.

Donate button

The Donate button will link to Film Efiko's selected external donation platform. Direct payment processing on the website is not included.

06 / Performance, SEO & PagesFilm Efiko

Performance, SEO and Website Pages

Very fast performance

The website will be custom-built in Next.js rather than assembled with a heavy public-facing WordPress theme or page builder. This allows the frontend to load only what each page needs.

  • Fast cached delivery through Vercel.
  • Optimised and correctly sized images.
  • Reduced unnecessary scripts and theme code.
  • Responsive loading for mobile devices.
  • Performance testing before launch.

Automatic SEO management

Editors will manage titles, descriptions and other SEO information from WordPress. The Next.js website will automatically apply the information to each page.

  • Search-friendly page titles and descriptions.
  • Automatic social-sharing previews.
  • Canonical URLs and structured article information.
  • XML sitemap and search-engine indexing support.
  • Redirects from important existing URLs.
  • SEO-friendly category, author, issue and archive pages.

Website pages

Homepage, article pages, category pages, author and columnist pages, issue and cover pages, search, archives, About, Contact, Advertise, Privacy, Terms and other agreed standard pages.
